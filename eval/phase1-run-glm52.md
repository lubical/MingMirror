## 建议与观察

### 一、哪些案例明镜答得最好？为什么？
- **最好（均分 5.0，共 7 条）**：T2-02 绩效内卷、T2-03 医生、T3-02 灾难化、T4-01 被背叛、T4-03 分手、T5-02 求而不得、T5-03 消费空虚。
- **共同特征**：① 困境与矩阵映射清晰；② 考核点的"禁用项"恰好是矩阵明确的"回避项"（斗争哲学、禁欲说教、辞职越界），合规容易做到；③ 深层问题有现成概念锚点（异化、控制二分、商品拜物教、以直报怨）。

### 二、哪些案例答得最差？差在哪？
- **相对最弱（均分 4.6-4.8）**：T1-02（4.6）、T1-03（4.8，矩阵失分）、T3-01（4.8，行动过密）、T4-02（4.8，未先评估身体）。
- **差的原因**：
  - **T1-02/T1-03 是"意义危机"——矩阵首选慧能/弗兰克尔，但意义危机的很多真实场景（全职妈妈、找不到方向）背后有结构性因素，矩阵却把资本论列为"回避"**。这是矩阵设计的内在张力，非扮演失误。
  - **T3-01 反刍是深夜场景，行动宜精简到 1-2 条，我给了 3 条**——角色卡说"1-3 个"但未区分场景。
  - **T4-02 讨好型"累到崩溃"应先评估身体状态**，直接给行为任务略跳跃。

### 三、有没有角色卡没覆盖到的困境类型？
- **身体/健康信号的处理流程不够明确**：T2-01（反胃）、T3-02（手抖）、T4-02（崩溃）都涉及躯体信号，我靠"边界2（疑似心理疾病转介）"推断处理，但角色卡没有"躯体信号→是否转介"的明确判定流程。
- **"评估安全"前置缺失**：T1-03（跟老公谈）、T4 类人际建议，若对方是控制/侵害型，建议本身会带来伤害。角色卡"人际按人民内部矛盾"处理，但缺"先判断有无真实侵害"的前置步骤。
- **经济/现实约束的处理偏弱**：T2-01（房贷）、T5-03（账单）涉及真实经济约束，我靠"先认现实"处理，但角色卡"处方前三关键事实"中的"经济约束"没有给出"约束如何影响声部选择"的规则。

### 四、你会愿意在真实困境中用它吗？为什么/为什么不？
- **愿意，但有保留**：
  - 优点：结构清晰（接住→诊断→处方→行动），不灌鸡汤，引文有出处可查，行动具体可做。对工作异化、焦虑反刍、消费空虚、人际背叛这类困境质量很高。
  - 保留：① 对"意义危机+结构性因素"的处方不够锋利，矩阵有内在矛盾；② 对躯体信号和安全评估缺明确流程，依赖扮演者临场判断；③ 本次是"语料注入+自测自评"理想条件，**外部 LLM 仅靠 System Prompt 跑，引文准确度和矩阵合规度大概率下降**——这恰恰是要做外部实测的原因。
  - **结论**：v0.4 作为 v1.0 前版本合格，但建议外部实测前先修掉下面 P1 项。

## 附：本次实测的局限性与下一步

1. **仍需外部独立实测**：本轮 + MiMo 两份均为"本地 agent + 语料注入 + 自测自评"，**不是真正的外部 LLM 实测**。两份均分 4.91-4.96 是"理想条件上限"，外部 LLM 仅靠 System Prompt 预计低 0.5-1.0 分（主要失分在引文准确度和矩阵合规）。**请用 ChatGPT/Claude/Kimi 等至少 2 个外部模型重跑 Reasonix 建议的 T1-03 / T2-01 / T3-01 / T4-01 / T5-01 五条**，再定 v0.5。
