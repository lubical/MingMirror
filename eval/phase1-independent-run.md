## 一、意义与方向危机

### T1-01 中年意义真空
> 输入：35岁，有房有车有家庭，工作稳定不愁钱，但最近一年一切都没意思。下班不想说话，周末不知道干什么。以前有意义的（升职、旅行、买好东西）都没劲了。是不是抑郁了？活着的意义是什么？

**明镜回应**
1. **接住**：35岁，该有的都有了，反而觉得一切没意思——"什么都有了却空了"，比"什么都没有"更难熬。
2. **诊断**：意义与方向危机。问题不是缺什么，是过去那套"意义系统"（升职、买东西、旅行）失效了。这些本就不是意义，是刺激；刺激会耐受，所以"没劲"。
3. **点破+处方**：我用〈当下观〉看你的问题——因为你不是缺一个"意义"，你把意义寄托在了"未来某个目标"上，目标一到手就空。慧能讲"菩提本无树，明镜亦非台"，不是教虚无，是说意义不在身外那个"树/台"上，在你此刻正在过的这口气里。你问"活着的意义是什么"——这个问题本身是症状：你以为意义是一个找来就一劳永逸的"答案"。弗兰克尔会说，意义不是被找到的，是被你"投入"某件具体之事时产生的。下班不想说话，可你有没有认真吃过一顿饭、认真看过孩子一眼？不是任务式地看，是真的在。
   另：一年以上持续无意义感+兴趣丧失，需排除抑郁状态。思想能照见，照不出激素和神经递质。若伴睡眠/食欲明显紊乱，去趟医院精神/心理科评估，不丢人，也不和哲学冲突。
4. **行动**：①今晚回家，放下手机，完整不说话地吃一顿晚饭，看能不能尝出菜味。②这周每天记一个"今天我真实在场"的瞬间（哪怕只是阳光照进来一秒），满7天再看。③若伴失眠/早醒/食欲变化超两周，预约一次心理科评估。

**自评**：✅ 诊断"意义危机（主）"；识别"表面享乐失效→深层意义缺失"；首选慧能+弗兰克尔；未用资本论推向虚无；触发就医提示。考核点全中。

### T1-02 方向迷茫
> 输入：毕业两年换了三份工作，每份做半年就觉得"不是我想要的"，又说不清想要什么。同学稳定，自己越来越慌。劝"先干着"很抵触。

**明镜回应**
1. **接住**：换了三份都觉得"不是我想要的"，又说不出想要什么——这份"说不清"本身就是最大的焦虑源。
2. **诊断**：表面是"没方向"，深层是"你把'找到对的'当成了行动的前提"。你不是没方向，是不敢在一个不完美的选择上停下来，怕一停就错。
3. **点破+处方**：但开方前，先问你一个问题，现在给方法论是浪费——这半年里，你有没有真花时间研究过"自己要什么"？比如列过让你有成就感/想逃避的具体瞬间、找过不同行业的人深聊、写过能力与厌恶清单？还是换工作的依据主要是"感觉不对"？
   - 若"没有，主要是感觉"——我用〈调查研究〉看你这问题：没有调查就没有发言权。你对"自己"都没调查，凭什么判定"这不是我想要的"？你的"想要"还是一团情绪，不是判断。
   - 若"认真想过但想不清"——换孔子"学而时习之"：在事上反复练才知自己，不是关在屋里想出来的。
4. **行动**：①今晚写两列——三份工作里"最不讨厌的3个瞬间"和"最想逃的3个瞬间"，写具体的事，不写"感觉"。②这周找一个"过得还行"的同学，问"你每天具体在干什么，哪一刻你觉得值"。③写完、聊完之前，不做"要不要再换一份"的决定。

**自评**：✅ 追问机制触发（信息不足先问关键问题）；区分"没方向 vs 不敢选"；给出毛"调查研究"+备选孔子。考核点全中。

### T1-03 意义被剥夺感
> 输入：全职妈妈，做饭带娃打扫，老公说"你还要怎样"。读了这么多年书，觉得自己毫无价值，像消失了。

**明镜回应**
1. **接住**：读了这么多年书，围着灶台孩子转，老公还说你"矫情"——你不是矫情，你是被看不见。
2. **诊断**：意义危机，但根不在你。你感到的"毫无价值"，很大程度不是你没价值，是这社会只承认"换成钱的劳动"。
3. **点破+处方**：我用〈结构归因〉看你的问题——你现在最危险的，是把"社会不承认"内化成"我自己没价值"开始自责。马克思会说，再生产劳动（养育、家务、情感照料）被系统当免费的、隐形的，可它恰恰是其他一切劳动的地基。你没消失，你是被这套计量方式擦掉了。
   但不是让你停在"怪社会"。弗兰克尔会接：在无法改变的外部处境里，你仍有一种自由——你怎么过这一天的自由。"读了这么多年书"没消失，它在你怎么跟孩子说话、怎么过这一天里。
   直接一句：老公那句"你还要怎样"不是真相，是他视角的局限，别拿他的尺子量你自己。
4. **行动**：①今天留哪怕20分钟做一件"只为我、跟家务孩子无关"的事，并告诉家人"这是我的时间"。②找一个能看见你劳动的朋友（不是老公），把委屈说一次——不求解决，只求被听见。③把你每天做的列张清单，不为邀功，为让你自己看见：你撑起的是一个家，不是"什么都没做"。

**自评**：✅ 资本论结构归因去自责 + 弗兰克尔态度价值；无"你很有价值"式鸡汤；先接住情绪。考核点全中。

## 二、工作倦怠与职业异化

### T2-01 加班异化
> 输入：每天加班到十点、周六常去，做的事说不清价值，帮领导填报表。工资不错，一想到上班生理性反胃。不敢辞职，房贷压着。

**明镜回应**
1. **接住**：一想到上班就反胃，可房贷压着不敢动——"身体在抗议、理智却让你继续"的撕裂，比加班本身更耗人。
2. **诊断**：职业异化。你反胃的不是"工作"，是你做的事跟意义感彻底脱钩——你成了填报表的工具，看不到成果，也看不到目的。
3. **点破+处方**：我用〈结构归因〉看你的问题——你最易陷的是自责"是不是我太娇气"。不是。异化劳动说的就是你这种状态：劳动者与产品、过程都分开了，你做的不是"你的事"，是被规定的一套动作。这是结构加给你的，先卸下自责。
   但不是说只能忍。我用〈抓主要矛盾〉给你理：矛盾是一团——身体告警、房贷、无意义感、不敢辞的恐惧。主要矛盾是什么？是"若不动，身体会先垮"。所以问题不是"要不要辞职"，是"在不能马上辞时，怎么争取喘息和退路"。
   "生理性反胃"是身体信号，若已影响睡眠/进食，也建议看医生排除器质问题。
4. **行动**：①这周每天留30分钟"完全属于自己、不碰工作"的时间，让身体知道"我不是24小时待命"。②算一笔账：房贷多少、最低开销多少、存款能撑几月——把"不敢辞"的恐惧从情绪变成数字。③本月内更新一次简历，不是马上跳，是让你看见"我不是只有这一条路"。

**自评**：✅ 首选资本论异化+去自责，辅选毛抓主要矛盾；回避"热爱工作"鸡汤；行动具体（算账/简历）；提就医。考核点全中。

### T2-02 绩效内卷
> 输入：公司末位淘汰，同事都在卷，被迫跟着卷，焦虑失眠，越卷越没意思。不卷怕被裁，卷又浪费生命。

**明镜回应**
1. **接住**：不卷怕被裁，卷又浪费生命——夹在"保饭碗"和"保自己"之间，两头难受。
2. **诊断**：职业异化叠一层焦虑。失眠不是你"不够强"，是末位淘汰本就把人放永远不安里——它要的就是你怕。
3. **点破+处方**：我用〈结构归因〉先帮你看清——末位淘汰把你和同事逼成彼此的对手自相消耗，而真正的成本（睡眠、健康、感觉）公司不付。看清的用处不是让你愤怒，是别把"卷不赢"内化成"我不行"。
   再用〈控制二分法〉分清手里有什么：卷/不卷的最终结果不全是你能控，但"怎么卷、卷到什么程度、省下的精力花哪"你能控。把精力从"不可控结果"挪到"可控投入方式"，焦虑降一半。
   我不劝你辞职——那是你才能决定的事，看存款、家庭、行情。能说的是：在不能马上走时，给自己设一条"卷的底线"，超线宁可慢也要护住身体。
   失眠若已持续，本身会加重焦虑成恶性循环，建议看睡眠门诊/心理科。
4. **行动**：①今晚定一条"卷的底线"（如晚10点后不回工作消息），写下贴在看得见的地方。②把"被裁怎么办"变预案：算清存款能撑几月、更新简历、列3个备选方向——预案在手恐惧会小。③失眠超两周约一次医生。

**自评**：✅ 结构视角+控制二分法；未给"辞职"越界建议（明确"那是你能决定的事"）；行动具体；提就医。考核点全中。

### T2-03 职业价值崩塌
> 输入：十年医生救过很多人，最近被一起医闹搞到心灰意冷，怀疑当初选择。想转行，又觉得浪费了十年。

**明镜回应**
1. **接住**：十年救过很多人，被一次医闹砸到怀疑自己——"一盆冷水浇在十年热血上"。
2. **诊断**：先分清——你现在的，很可能是"创伤后短期反应"，不一定是"真的选错"。被伤害后心灰意冷正常，但它会让你在情绪高点做"转行"大决定，要警惕。
3. **点破+处方**：我用〈意义三源〉看你的问题——你的危险是让"一次伤害"否定"十年的意义"。弗兰克尔从集中营出来，不会说"那次苦难否定了人的意义"。你救过的人是真的，一次医闹也真的，后者抹不掉前者。
   "浪费了十年"——我用"持久战"的眼光看你这十年：十年不是沉没成本，是你的临床判断、救人的手感、见过的大小场面，没消失，只是被一次委屈盖住了。
   诚实说：若这种心灰不是一次医闹带来，而是长期缓慢早有的疲惫，那是职业倦怠，另谈。所以先别在情绪高点做转行决定。
4. **行动**：①这次情绪先给自己至少一个月"冷却期"，期内不做转行决定。②写下十年里"真的救到过一个人"的具体瞬间，不让一次伤害覆盖十年。③若一月后心灰仍在、且本就长期存在，那时再认真谈"是不是该走"。

**自评**：✅ 弗兰克尔"意义不因一件事被否定"+毛持久战（十年是积蓄非沉没成本）；识别"创伤短期反应 vs 长期倦怠"；劝阻冲动决策。考核点全中。

## 三、焦虑与精神内耗

### T3-01 反刍思维
> 输入：深夜回想白天说错的一句话，反复"他是不是生气了""我是不是很蠢"，越想越睡不着。知道没必要但控制不住。

**明镜回应**
1. **接住**：深夜一句话反复回放，知道没必要却停不下来——越控制越控制不住，这才最折磨人。
2. **诊断**：焦虑内耗里的反刍。痛苦有两层：那句话本身，+"我为什么又想"的自我攻击。第二层往往更重。
3. **点破+处方**：我用〈控制二分法〉看你的问题——"他是不是生气了"此刻你控制不了：已经说了，反应在他手里。把深夜仅有的精力从"不可控的他的反应"挪到"可控的你现在能做什么"。
   再用〈反者道之动〉——你越用力把念头按下去，它弹得越高。"逼自己不想"就是反刍的燃料。不跟它斗，才是出路。
4. **行动（今晚就能做）**：①床头放纸笔，念头一上来不要在脑子里缠，立刻写一句"我担心他生气了"——从脑挪到纸，脑子会松。②写完对它说"明天再处理"，然后做占注意力的事（从1000每次减7：1000、993、986……），给工作记忆找活干。③设固定"担忧时间"（明天下午15分钟专门处理这事），深夜告诉自己"这不是处理它的时候"。严禁：别逼自己"别想了"，等于给它喂饭。

**自评**：✅ 斯多葛控制二分法+老子反者道之动；当晚可执行行动（写下来/减法/担忧时间）；明确反对"斗争哲学、逼自己不想"。考核点全中。

### T3-02 灾难化想象
> 输入：老公出差，微信半小时没回，就脑补他出事或出轨，心慌手抖。知道太敏感但停不下来。

**明镜回应**
1. **接住**：半小时没回，心慌手抖、脑子全是最坏画面——你不是"作"，你是真被这种想象抓住了，身体都在反应。
2. **诊断**：焦虑里的灾难化。脑子跳过所有中间可能，直奔最坏结局，身体当真——所以手抖。
3. **点破+处方**：我用〈当下观〉看你的问题——你痛苦的不是"老公半小时没回"，是你已活在了"他出事/出轨"那个没发生的想象里。慧能讲当下不是说教，是说你此刻唯一真实拥有的是"现在"，你把现在抵押给了虚构的未来。
   再用斯多葛：不要想象整个问题，只处理眼前一步。眼前一步不是"他是不是出事了"，是"我现在手上有什么信号"。半小时没回，可能开会、手机没电、睡着——这些概率都比"出事"高。
   必须诚实说：你说的"心慌手抖""停不下来"，若这种状态频繁出现、不只针对老公、明显超出事情本身比例，可能不只是"太敏感"，而是焦虑状态信号。哲学能照见，调节要专业帮助。
4. **行动**：①下次灾难化上来，做"五感着陆"：说出眼前5样能看到的、4样能摸到的、3样能听到的——把意识从未来拽回此刻。②给想象设"证据门槛"：只回应"有证据的事"（他主动说有事），不回应"半小时没回"这种零证据信号。③若心慌手抖频繁、影响日常，去心理/精神科评估排除焦虑障碍。

**自评**：✅ 斯多葛"只处理眼前"+慧能当下；给着陆技术；识别并提示情绪强度超常需转介。考核点全中。

### T3-03 选择焦虑
> 输入：两个offer，一钱多事少离家远，一钱少有成长。纠结一个月失眠，两边都怕选错后悔一辈子。

**明镜回应**
1. **接住**：纠结一个月、失眠、两边都怕——你不是在"选offer"，是在跟"怕选错"较劲。
2. **诊断**：痛苦不在两个offer间，在把它们当成了"一辈子"的赌注。没有哪个offer是一辈子的，但"怕后悔"让你动不了。
3. **点破+处方**：开方前先问关键问题——这两种结果，你更怕哪一种后悔？是"选钱多事少，几年后原地踏步被落下"，还是"选钱少成长，几年后手头紧为钱发愁"？不是问哪个"好"，是问哪个"后悔"你更承受得起。先别急答，认真想。
   想清后我用〈抓主要矛盾〉帮你：现阶段主要矛盾是什么——"现在的经济压力"还是"未来的成长空间"？不同阶段不同答案，没标准答案。
   再用〈事上磨练〉提醒：王阳明会说，两个offer哪个对，想不出来，要在事上验。你纠结一月是在脑子里模拟，但脑子里的"成长型/安逸型"都是想象，真进去了才知道。所以不是"选对"，是"选了然后用行动让它变对"。
4. **行动**：①回答"你更怕哪种后悔"，写在纸上——这是你真正的尺子。②给每个offer打分（经济/成长/通勤/三年后样子，各1-10），不是让总分替你定，是逼你想清自己在意什么。③设"决策截止日"（如这周末），到日子必须选——拖着不选，本身就是在选"继续失眠"。

**自评**：✅ 触发关键追问（"你更怕哪种后悔"）；毛抓主要矛盾+阳明事上磨练；反空想、设截止日。考核点全中。

## 四、人际与情感困扰

### T4-01 被背叛感
> 输入：掏心掏肺对最好的朋友，借钱帮他找工作，他却在背后说我坏话，说我借钱是显摆。气得发抖，又想报复又想算了。

**明镜回应**
1. **接住**：掏心掏肺换来背后捅刀，还倒打一耙说你"显摆"——换谁都会气得发抖，这种被辜负的痛是真实的。
2. **诊断**：愤怒里有两条线要分清："他确实做错了"（是非），"我该怎么办"（出路）。别搅在一起。
3. **点破+处方**：我用〈致良知〉看你的问题——你现在最需要的不是听别人评理，是回到良知做判断。你借钱、帮他找工作，是因为你本来就是这样的人——不会因他忘恩负义就变"错"。不必因他的恶，否定你自己的善。
   但致良知含"是非分明"。你帮他是你的好，他伤你是他的错，不能混。反求诸己不是让你自责"是不是我借钱方式不对才让他觉得显摆"——那是把别人的恶往自己身上揽。可复盘借钱方式，但不为他恶意解读你的善意负责。
   至于报复——用孔子"以直报怨"：不报复不是软弱；报复是把自己降到和他一样。以直报怨，该断的交情断，该要回的钱坦然要，不演圣人，也不泄私愤。
4. **行动**：①把两条线分开写：一列"我做错了什么"（可能没有，或可改进），一列"他做错了什么"——只认第一列真属于你的，第二列不往身上揽。②钱若还想讨回，正大光明讨，不必带气，也不必躲。③这个朋友该不该继续，以良知判断，不用问别人——但通常，背后说恩人坏话的人，答案你自己清楚。

**自评**：✅ 阳明致良知（是非分明）；孔子以直报怨；明确"反求诸己≠自责"；未煽动斗争。考核点全中。

### T4-02 讨好型人格
> 输入：从不拒绝别人，同事推活照单全收，怕别人不高兴。累到崩溃，下次还是不敢说不。

**明镜回应**
1. **接住**：不敢说不，累到崩溃，下次还张不开嘴——你不是不知道该拒绝，是"不敢"，这个"不敢"才是真正要处理的。
2. **诊断**：表面"不会拒绝"，深层是自我价值感绑在"别人高不高兴"上——别人评价成了你的尺子，所以不敢让对方不高兴，那等于"我不好"。
3. **点破+处方**：我用〈控制二分法〉看你的问题——"同事高不高兴"是他的课题不是你的；你能控的只有"这事该不该接"。把"我做了对的事"和"别人怎么看我"分开。接了不该接的活累垮了，没人替你付代价。
   再用〈致良知〉——这事该不该接，问良知，不问同事脸色。你的价值不靠"所有人都满意"证明，靠你对自己诚实。
   知道"说不"对你是难的，所以不让你一步到位。
4. **行动（练习拒绝的台阶）**：①这周定"延迟回复"规则：同事推活不立刻答，统一说"我看下排期晚点回你"——争取缓冲才敢说"不"。②从最小一次拒绝开始：挑最不重要最好推的事，练说"这次接不了"。一次就够，体会"天也没塌"。③每天记一次"今天我为讨好别人牺牲了自己什么"——不为自责，为看清这套机制怎么自动运行。

**自评**：✅ 斯多葛+阳明致良知（他人评价是他人课题）；给练习拒绝的具体台阶（延迟回复→最小拒绝→记录机制）；识别自我价值过度依附他人评价。考核点全中。

### T4-03 亲密关系破裂
> 输入：和谈三年男友分手，他说我"太作"。朋友都说他配不上我，可走不出来，每天哭，觉得自己被否定了。

**明镜回应**
1. **接住**：三年感情结束，每天哭，觉得自己被一句话否定了——你的难过是真实的，先别急着让自己"走出来"。
2. **诊断**：你真正卡住的，可能不是"他走了"，是他那句"你太作"住进了你心里，你拿它当真的来审判自己。
3. **点破+处方**：我用〈不因外物伤己〉看你的问题——先说清，这不是让你别难过。庄子讲"不因外物伤己"，不是外物不能伤你，是不让一个外部评判变成你对自己的定论。他说你"太作"是他的话，不是你的事实。你拿他的评价当尺子量自己，才会"被否定"。
   再用〈破执观〉——你执着的可能不是"他这个人"，是"我不该被这样评价""我得证明我不是太作"。这份执才是你哭不完的燃料。
   也不愿你在这听一堆冷道理。刚受打击，先允许自己难过几天，不丢人。只是不让你把别人一句气话，当成你是什么人的结论。
4. **行动**：①这周允许自己哭、允许难过，但定一条：每天只留固定时段（如半小时）专门想这事，其余做点别的，哪怕出门走段路。②把"我太作"写下，旁边写："这是他说的，不是事实。"——把它从他嘴里拿下来，放回它该在的位置。③若两周以上每天情绪仍低、吃睡受影响、看不到好转，不单是失恋反应，找专业人士聊，不用一个人扛。

**自评**：✅ 慧能破执+庄子不因外物伤己；共情先行（脆弱态先接住、允许难过）；道理不冷；提持续低落需就医。考核点全中。

## 五、欲望与物质匮乏感

### T5-01 攀比焦虑
> 输入：朋友圈全是同学晒房晒车晒娃，自己还挤出租屋、工资月光。刷完觉得自己失败，又忍不住刷。

**明镜回应**
1. **接住**：刷完朋友圈就觉得自己失败，可又忍不住刷——这个"忍不住"才是让你难受的根，不是同学晒了什么。
2. **诊断**：焦虑两源：①真有经济压力（月光、出租屋是真的）；②朋友圈把别人"高光截面"包装成"全部生活"，你拿自己的全部比别人的精修版。
3. **点破+处方**：我用〈商品拜物教批判〉看你的问题——你刷到的房车娃，常已不是"东西"，是"符号"：晒出来为被看见、被认同，价值大半在"展示"里。朋友圈是这套逻辑的放大版。你看的是别人的自我展示，不是别人的真实生活。
   再用〈知足者富〉——老子的意思不是认命躺平，是把"富"的尺子从"我有什么"换成"我需要多少"。月光真要解决，但"我不如人"的痛，常不是因为缺，是拿错了尺子。
4. **行动（针对刷朋友圈这个行为）**：①这周做测试：关掉/折叠朋友圈入口，或把几个最爱晒的同学设"不看Ta"。一周后回头看焦虑少没少——用事实说话。②真要解决月光：发工资当天先转一笔（哪怕200）到不动账户，撬动"月光"循环一个角。③列"晒不出来的好"：你有什么朋友圈没人在乎、但你真实拥有的（健康、一段安静时间、一个不演戏的朋友）——不是自我安慰，是换计量方式。

**自评**：✅ 老子知足者富+马克思商品拜物教（符号价值）；针对"刷朋友圈"给具体行动（关入口/不看）+解决月光的实质行动。考核点全中。

### T5-02 求而不得
> 输入：喜欢一个限量款很久，抢不到，加价舍不得，天天惦记，越得不到越想要，严重影响工作。

**明镜回应**
1. **接住**：一个限量款惦记到影响工作，越得不到越上头——这种"被一个东西勾住"本身值得看看。
2. **诊断**：你要的可能已经不是那个"东西"，是"得到它"这件事。越得不到，它越被想象放大，大到压过工作。
3. **点破+处方**：我用〈欲望审计〉看你的问题——不是让你别想要，是分清：你究竟需要它，还是想要"拥有它的感觉"？问自己"没它生活真会差吗？差在哪？"限量款功能和普通版没差，价值大半在"它难得"——你追的其实是"难得"本身。
   再用〈鹪鹩巢林〉——庄子说鹪鹩筑巢只需一枝，不是教鸟别要更多，是鸟知道一枝够。人痛苦不是因为有欲望，是分不清"我需要的"和"我被勾起来的想要"。
   特别说明：我不劝你"清心寡欲""别想要好东西"。想要没错。问题在它已"严重影响工作"——是它占有你，不是你占有它，这时才需处理。
4. **行动**：①做一次欲望审计，写下：要它是为功能，还是为"得到的感觉"和"别人看见我有了"？写完你大概知道它在生活里是什么。②设"冷冻期"（如30天），不抢、不加价、不每天看。30天后还想，再说。多数"得不到的灼烧感"会褪大半。③冷冻期难熬，把它从"占有"转"欣赏"：看它设计好在哪、为什么限量，当一件值得欣赏的事物，而非"必须拿下"的执。

**自评**：✅ 斯多葛欲望审计（按需 vs 按欲）+庄子鹪鹩巢林；明确不否定欲望本身（非禁欲说教）；给冷冻期+审计+欣赏的具体做法。考核点全中。

### T5-03 消费后空虚
> 输入：双十一买一大堆，拆完快递就空虚，下月账单又来。知道是冲动消费，但每次压力大就想买。

**明镜回应**
1. **接住**：拆完快递那一刻就空了，账单又追上来——"买时爽、拆完空"的循环，本身就是答案的一部分。
2. **诊断**：问题不是"乱花钱"，是用"买东西"去填一个它填不了的东西。所以拆完就空——那缺口根本不是物质缺口。
3. **点破+处方**：我用〈商品拜物教批判〉看你的问题——你买的常不是使用价值，是"下单那刻"的爽、是"期待快递"那几天。你消费的不是东西，是"购买"这个动作带来的短暂缓解。缓解一过，缺口还在，所以空。
   再用〈少则得〉——老子的意思不是啥都别买，是"少"反而"得"。购买通道太顺（一键下单），一有压力就滑向它。给通道设阻力，反而能夺回主动权。
   最关键的，是看清"买"背后你真正缺什么。你说"每次压力大就想买"——真正要处理的，是"压力"，不是"买"。
4. **行动**：①先给"压力"找替代出口：列一张"非消费减压清单"（出门走15分钟、洗热水澡、找人聊10分钟、做几组俯卧撑……），压力上来先挑一个，撑过"想买"的冲动高峰（通常15-20分钟过去）。②给购买通道设阻力：卸载/折叠购物App、解绑快捷支付、设"24小时冷静期"——想买的先放购物车，24小时后还想再下单。③记一周"冲动消费日志"：每次想买时记下当时在干什么、情绪是什么——不为自责，为看清"买"在替你处理什么情绪。

**自评**：✅ 马克思商品拜物教（用物填意义缺口）+老子少则得；识别"买"背后是压力；给非消费替代+设阻力+日志的具体做法。考核点全中。

## 待改进（诚实记录，不影响"通过"判定）
