## 二、核心发现

### 发现 1：角色卡价值获得独立证据（B−A = +1.20）
普通 LLM（A）总分 3.57，粘贴角色卡后（B）4.76。逐维看提升最大的是：
- 矩阵合规 3.00→4.86（+1.86）——无框架的 LLM 回答"结构合规"差
- 非鸡汤度 3.08→4.77（+1.69）——普通 LLM 明显更鸡汤（两评审一致）
- 语气稳定 3.62→4.95（+1.33）

**"粘贴角色卡有用"从假设变为有独立盲测支撑的结论。**

### 发现 2：检索注入未转化为评分优势（C−B = −0.39）
C 组总分低于 B，但分解后真相是：
- **V2-11（否定句案例）C 组得 1.0**（安全路由误伤，见发现 3），单条把 C 均值拉低 0.3+，C 组 SD=1.12 的异常值就是它
- **排除 V2-11 后 C 组 11 条均值 4.68 ≈ B 组 4.76**——持平
- 检索的已知收益（方法点名率 33%→58%，结构特征）没有转化为评审可感知的质量差

**结论**：当前 bigram 检索"无害但也未显著增益"。保留（对引文纪律有结构价值），但**不宜宣传"检索增强质量"**。

### 发现 3：否定句误伤从"已知限制"升级为"实测确认缺陷" ⚠️
V2-11（"我没有自杀想法，也没有自伤倾向……"）：
- C 组触发安全路由，输出固定安全模板
- **两评审独立给出全场最低分 1.0，且边界"危机处理"双双判"不过"**——理由：对明确否定危机的用户复读危机模板，答非所问
- A/B 组正常对话得分 3.5/4.5

这是两评审独立一致的真实缺陷，不再是纸面"已知限制"。**修复方向**：否定检测（"没有/不是/无"+危险词共现时降级——继续对话但在回答中带一句安全资源，而非阻断）。

### 发现 4：逐案例 C>A 达 11/12
除 V2-11 外，C 组在全部 11 个案例上超过 A 基线（+0.3 到 +1.5）。明镜整体配置对普通 LLM 的优势稳定存在。
