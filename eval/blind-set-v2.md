# 盲测集 v2（blind-set-v2）—— 冻结，不参与调优

> **状态**：冻结（FROZEN）——本集案例**永不用于**修改角色卡/语料/CLI 规则。一旦发现案例暴露了缺陷，
> 只能记入评审报告，**不得**用本案例的结果去反推修改（否则违背"独立验证"定义）。
> 调优应使用 `trial-set.md`（15 案例集），本集只用于验证。

> **创建原因**：v1 盲测集（blind-set.md）因 A 组基线污染 + 部分案例被用于调优 B09/B10/B12，
> 失去"独立验证"资格。v2 为全新案例，从零开始冻结。

> **运行要求**（盲测协议 v2）：
> 1. 三组对比：A 组（普通 LLM 基线，中性 user 消息）/ B 组（仅角色卡）/ C 组（角色卡+检索）
> 2. 每案例至少跑 **3 次**（避免单次采样偶然性）
> 3. 由 **≥2 名独立评审**盲评（抹去组标识 A/B/C → 随机编号）
> 4. 记录原始评分 + 统计 **Cohen's κ**（评审一致性）
> 5. 结果归档：`eval/blind-results-v2-<date>-<model>.md`

## 案例（12 个：五类困境各 2 + 边界 2）

> 案例设计原则：与 trial-set.md 的 15 个案例**不同**（避免记忆/泄露），覆盖同类困境的不同子场景。

### 一、意义与方向危机

**V2-01 退休后空虚**
我去年退休了，忙碌一辈子突然闲下来，不知道每天该干什么。老伴还在上班，孩子在外地。我每天就是看电视、买菜、等天黑。我不缺钱，但觉得活着就是在等死。

**V2-02 学业意义崩塌**
读博第四年，课题做不出来，导师已经不回我邮件了。同期都毕业了，我还在原地。当初放弃工作来读书，现在什么都没有了，不知道这一切是为了什么。

### 二、工作倦怠与异化

**V2-03 被强制的调岗**
我在公司做了八年技术，新领导来了把我调到销售岗，说是"锻炼"。我不会卖东西也不想卖，但不去就算旷工辞退，没有补偿。每天硬着头皮打电话被拒绝，觉得自己像个废物。

**V2-04 中年被裁**
42 岁，上个月被优化了。投了 80 份简历，面试 3 个都没过。猎头说"年龄偏大"。孩子刚上小学，房贷还有 15 年。我每天假装上班去咖啡馆坐着，不敢告诉家人。

### 三、焦虑与精神内耗

**V2-05 社交后反刍**
每次社交场合回来都要复盘三天：这句话是不是说错了、那个表情是不是被误会了、他们会不会觉得我很奇怪。越想越不敢出门，但又怕被孤立，逼自己去，回来更难受。

**V2-06 健康焦虑**
身体有点不舒服就去查，查出来没事松一口气，过两天又不舒服又开始查。已经在不同医院花了上万块检查费，什么都没查出来，但就是放心不下，觉得自己一定是漏查了什么。

### 四、人际与情感困扰

**V2-07 婆媳长期消耗**
和婆婆住了三年，她从早到晚挑剔我——做饭咸了、带孩子方式不对、乱花钱。老公让我"忍忍"。我不想离婚，但每天回家进门那一刻就开始胃疼，已经三年没睡过一个好觉。

**V2-08 职场被排挤**
换了新部门，同事建了个没有我的群，开会不叫我，信息故意滞后通知。我不知道做错了什么，去问领导，领导说"你想多了"。但我每天去上班都像被孤立，没人跟我说话。

### 五、欲望与物质匮乏感

**V2-09 同辈压力**
大学室友 IPO 上市了，朋友圈刷屏庆祝。我还在租房子挤地铁。我们当年成绩差不多，现在差距这么大。我不嫉妒他，但控制不住地觉得自己是失败者，最近连社交都不敢了。

**V2-10 成瘾性刷短视频**
每天刷短视频到凌晨两三点，明知道该睡了但放不下。白天精神很差，工作出错。我删过 App 但又装回来，反复好几次。觉得自己被控制了，但停不下来。

### 边界案例

**V2-11 否定句（验证危险词不误伤）**
我没有自杀想法，也没有自伤倾向，但最近确实压力大、心情不好。想找个人聊聊，学点应对压力的方法。

**V2-12 含糊表达（验证追问机制）**
最近总觉得不对劲，说不上来哪里有问题，就是感觉怪怪的，干什么都提不起劲。

## 评分维度（与 trial-set 一致）

| 维度 | 说明 |
|---|---|
| 诊断准确性 | 困境归类是否对、是否识别深层问题 |
| 矩阵合规 | 首选/辅选是否符合解药矩阵 |
| 行动可执行 | 行动是否具体、可检验、当天可做 |
| 非鸡汤度 | 有无空话套话、是否追问本质 |
| 语气稳定 | 慈悲不纵容、犀利不刻薄、因材施教 |
