## 回填指引（每轮实测后）

1. 得分 ≤ 3 的维度 → 记入 `docs/superpowers/specs/2026-08-07-spiritual-mentor-design.md` 的修订清单（§12 追加"实测修订记录"）
2. "矩阵合规"失分 → 原因大概率是角色卡矩阵不够显式 → 修订角色卡对应行
3. "行动可执行"失分 → 角色卡 §"行动三原则"需强化示例
4. 语料缺口（该引的原文库里没有）→ 记录案例号，语料库建设时优先补齐
