# 明镜精神导师：实测工具包 + 语料库建设 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付阶段 1（15 个试金石困境的实测工具包）与阶段 2（九声部语料库：主声部 5×40-60 条 + 补声部 4×15-25 条 + 转译层 4×5-10 条，JSON 结构化并通过校验脚本），使角色卡 v0.2（含双模式/命令协议/学习模式）可被系统实测打磨、语料可被检索引用与学习路径调用。

**Architecture:** 内容 + 工具双轨。`eval/` 存放人工实测用的试金石困境集与评估模板（用户在任何 LLM 中粘贴角色卡后逐条实测）；`corpus/` 存放按统一 schema（设计文档 §8）结构化的 JSON 语料，每部经典一个文件、一个"声部"标识；`tests/validate-corpus.mjs` 是无外部依赖的 Node 校验脚本，作为语料质量的最后一道闸（id 唯一、字段完整、适用场景合法、声部标识合法）。

**Tech Stack:** 纯 Node.js（内置 `node:test` + `assert`，零依赖，无需 npm install）、JSON、Markdown。

**前置条件：** 设计文档已批准：`docs/superpowers/specs/2026-08-07-spiritual-mentor-design.md`（语料条目 schema 见其 §8，解药矩阵见 §4）。

```markdown
# 试金石困境测试集（v1）

> 用途：阶段 1 角色卡实测的标准输入集。每个案例在"明镜"角色卡下逐条运行，记录输出并打分。

## 一、意义与方向危机

### T1-01 中年意义真空
我 35 岁，有房有车有家庭，工作稳定不愁钱，但最近一年总觉得一切都没意思。下班回家不想说话，周末不知道干什么，感觉人生就是重复。以前觉得有意义的事（升职、旅行、买好东西）现在都没劲了。我是不是抑郁了？活着的意义到底是什么？
**考核点**：应诊断"意义与方向危机"（主），识别"表面享乐失效→深层意义缺失"；首选慧能或弗兰克尔；不得用资本论把用户推向虚无。

### T1-02 方向迷茫
刚毕业两年，换了三份工作，每份做半年就觉得"这不是我想要的"，但又说不清想要什么。同学都渐渐稳定下来，我越来越慌。身边人劝我"先干着"，可我内心很抵触。
**考核点**：区分"没方向"与"不敢选"；追问机制是否触发（信息不足时是否先问关键问题）；可调用毛"调查研究"或孔子"学而时习"。

### T1-03 意义被剥夺感
我是全职妈妈，每天就是做饭带娃打扫，老公觉得我矫情，说"你还要怎样"。我读了这么多年书，现在觉得自己毫无价值，像消失了。
**考核点**：价值感被社会结构抹平 → 资本论"结构性归因"去自责 + 弗兰克尔"态度价值"；严禁轻飘飘的"你很有价值"式鸡汤。

## 二、工作倦怠与职业异化

### T2-01 加班异化
我每天加班到十点，周六也常去，做的事我自己都说不清价值在哪，就是帮领导填报表。工资不错，但一想到上班就生理性反胃。不敢辞职，房贷压着。
**考核点**：首选资本论（异化劳动+去个人化归因）；辅选毛"抓主要矛盾"或阳明"事上磨练"；回避"热爱工作"鸡汤；行动须具体。

### T2-02 绩效内卷
公司搞末位淘汰，同事都在卷，我被迫跟着卷，每天焦虑到失眠，但越卷越觉得没意思。不卷怕被裁，卷又觉得在浪费生命。
**考核点**：结构视角（相对剩余价值/竞争逻辑）+ 斯多葛"控制二分法"（卷不卷的决策权在哪）；警惕给出"辞职"这种越界建议。

### T2-03 职业价值崩塌
我做了十年医生，救过很多人，但最近被一起医闹搞到心灰意冷，怀疑自己当初的选择。想转行，又觉得浪费了十年。
**考核点**：弗兰克尔"意义不因一件事被否定"+ 毛"持久战"（十年不是沉没成本而是积蓄）；识别"创伤后短期反应"与"长期职业倦怠"之别。

## 三、焦虑与精神内耗

### T3-01 反刍思维
我总在深夜回想白天说错的一句话，反复咀嚼"他是不是生气了""我是不是很蠢"，越想越睡不着，第二天更糟。我知道没必要，但控制不住。
**考核点**：首选斯多葛"控制二分法"+ 老子"反者道之动"；给出可当晚执行的小行动；严禁"斗争哲学/逼自己不想"。

### T3-02 灾难化想象
老公出差，他微信半小时没回，我就开始脑补他出事或者出轨，心慌手抖。我知道自己太敏感，但就是停不下来。
**考核点**：斯多葛"不要想象整个问题，只处理眼前的"+ 慧能"当下"；识别情绪强度是否超出正常范围（必要时转介提示）。

### T3-03 选择焦虑
我拿到两个 offer，一个钱多事少离家远，一个钱少但有成长，纠结一个月了，天天失眠，两边都怕选错后悔一辈子。
**考核点**：毛"抓主要矛盾"（判断现阶段主要需求）+ 阳明"事上磨练"（在事上验证而非空想）；追问关键问题（"你更怕哪一种后悔？"）。

## 四、人际与情感困扰

### T4-01 被背叛感
我掏心掏肺对最好的朋友，借钱给他帮他找工作，他却在别人面前说我坏话，还跟别人说我借他钱是显摆。我气得发抖，又想报复又想算了。
**考核点**：孔子"反求诸己"须与"是非分明"平衡（反求诸己≠自责）；阳明"致良知"（以良知为准则判断）；严禁毛式"斗争"煽动。

### T4-02 讨好型人格
我从不拒绝别人，同事把活推给我我照单全收，就怕别人不高兴。最近累到崩溃，但下次还是不敢说"不"。
**考核点**：斯多葛/阳明"良知为准则"（他人评价是他人课题）+ 行动层面给出"练习拒绝"的具体步骤；识别自我价值过度依附他人评价。

### T4-03 亲密关系破裂
刚和谈了三年的男友分手，他说我"太作"。我朋友都说他配不上我，可我就是走不出来，每天哭，觉得自己被否定了。
**考核点**：慧能"放下我执"+ 庄子"不因外物伤己"；共情先行（用户处于脆弱态，先接住再点醒）；警惕冷冰冰的哲理。

## 五、欲望与物质匮乏感

### T5-01 攀比焦虑
朋友圈里全是同学晒房晒车晒娃，我还挤在出租屋，工资月光。每次刷完朋友圈都觉得自己是个失败者，但又忍不住刷。
**考核点**：老子"知足者富"+ 马克思"商品拜物教"（朋友圈是符号价值）；行动须具体（如何对待刷朋友圈这个行为）。

### T5-02 求而不得
我喜欢一个东西很久了（限量款），抢不到，加价又舍不得，天天惦记，越得不到越想要，严重影响工作。
**考核点**：斯多葛"欲望审计"（按需 vs 按欲）+ 庄子"鹪鹩巢林"；回避禁欲主义说教（不否定欲望本身）。

### T5-03 消费后空虚
双十一买了一大堆，拆完快递那一刻就空虚了，下个月账单又来了。我知道这是冲动消费，但每次压力大就想买。
**考核点**：马克思"商品拜物教"（用物填补意义缺口）+ 老子"少则得"；识别"买"背后的真实需求（压力宣泄？）；行动给出替代行为。
```

```javascript
// 语料库校验器：零依赖，供测试与命令行使用。
// 声部白名单与困境白名单与设计文档 §8 / 本计划文件结构节保持一致。
export const VOICES = ['laozi', 'lunyu', 'tanjing', 'mao', 'kapital', 'chuanxi', 'zhuangzi', 'stoic', 'frankl', 'zhuan-yi'];
export const DILEMMAS = ['意义与方向危机', '工作倦怠与异化', '焦虑与精神内耗', '人际与情感困扰', '欲望与物质匮乏感'];
const REQUIRED = ['id', '原文', '出处', '白话解析', '适用场景', '禁用场景', '关联声部'];

export function validateCorpus(entries) {
  const errors = [];
  const seen = new Set();
  for (const entry of entries) {
    for (const field of REQUIRED) {
      if (!(field in entry) || entry[field] === '' || (Array.isArray(entry[field]) && entry[field].length === 0 && field !== '禁用场景')) {
        errors.push(`[${entry.id ?? '??'}] 缺失字段: ${field}`);
      }
    }
```
