# 明镜

> 身是菩提树，心如明镜台——一位熔炼东西方智慧的**精神导师 AI**。
> 她不直接给答案，而是帮你照见自己。

明镜面对你的精神困境时，**先诊断、再开方、后给行动**——而不是甩给你一句金句或一锅鸡汤。她熔炼九大思想声部（毛泽东·方法论 / 老子 / 孔子 / 慧能 / 马克思 / 王阳明 / 庄子 / 斯多葛 / 弗兰克尔），按你的困境类型调用合适的思想，点破认知误区，给出当天就能做的小行动。

她应对五类高频困境：

| 困境类型 | 明镜会怎么做 |
|---|---|
| 意义与方向危机 | 慧能"当下"/弗兰克尔"意义三源"——不滑向虚无 |
| 工作倦怠与异化 | 马克思"结构归因"去自责——不灌"热爱工作"鸡汤 |
| 焦虑与精神内耗 | 老子"反者道之动"/斯多葛"控制二分法"——不逼你"别想" |
| 人际与情感困扰 | 孔子"反求诸己"/阳明"致良知"——不煽动斗争 |
| 欲望与物质匮乏 | 老子"知足者富"/马克思"商品拜物教"——不说教禁欲 |

> ⚠️ **安全边界**：明镜**不替代专业心理帮助**。涉及自伤/自杀/家暴/严重侵害，她会停止哲学对话，优先给出求助资源（心理援助 12356 / 家暴 12338 / 报警 110 / 急救 120）。

## 三种方式接触明镜

### 1. 粘贴角色卡（最快，任意 LLM）

把 [`prompts/mingtian-v0.8.md`](prompts/mingtian-v0.8.md) 全文复制，粘贴进 ChatGPT / Claude / GLM / DeepSeek / Kimi 等任意支持长上下文的 LLM，作为 System Prompt（或 Project 指令、或首条消息）。然后像和一个导师对话一样，说你的困境。

```
打开 prompts/mingtian-v0.8.md → 全选复制 → 粘贴进你的 LLM → 开始对话
```

角色卡是明镜的"灵魂"——所有诊断框架、解药矩阵、安全边界都在里面。无需安装、无需配置。

### 2. 本地 CLI（带语料检索，最完整）

明镜的 CLI 客户端在你的终端里运行，自带**九声部语料库的本地检索**（358 条金句 + 87 个概念 + 16 个方法），引用原文更准确，且支持 `/概念` `/对比` `/学习` 命令。

```powershell
# 配置（仓库根目录）
Copy-Item .env.example .env
# 编辑 .env，填入你的 LLM API key（GLM / DeepSeek / 通义，自带 key）

# 运行
dart run cli/bin/mingtian.dart
```

详见 [`cli/README.md`](cli/README.md)。CLI 代码（Dart）未来可复用到移动 App。

### 3. 纸版工具包（无 AI、无网络）

不想用 AI？明镜的诊断框架也物化成了可打印的自助审视工具：诊断矩阵速查卡、15 张方法卡、金句卡。翻开 → 识别困境 → 选方法 → 照步骤做。

详见 [`paperkit/README.md`](paperkit/README.md)。

## 明镜的思想库

明镜的回答不是 LLM 凭空生成，背后有一套结构化的思想资产支撑：

| 资产 | 内容 | 数量 |
|---|---|---|
| [角色卡](prompts/) | 明镜的"灵魂"——双模式、诊断框架、解药矩阵、安全边界 | v0.8（v0.1→v0.8 经多轮实测迭代） |
| [语料](corpus/) | 九声部金句，每条含原文/出处/白话解析/适用场景/禁用场景 | 358 条 |
| [概念](concepts/) | 跨声部的概念体系，链向关联语料 | 87 条 |
| [方法](methods/) | 每个方法的具体操作步骤（用户问"怎么做"时讲解） | 16 个 |
| [导读](guides/) | 每个声部的核心脉络、常见误读、回避边界 | 10 份 |
| [示例](examples/) | 完整对话示范（四步结构 + 点评） | 6 个 |

这套资产经过多轮外部 LLM 实测（GLM / mimoV2.5Pro）与盲测验证，质量稳定。详见 [`eval/`](eval/)。

## 快速开始（5 分钟体验明镜）

**最简方式——不装任何东西：**

1. 打开 [`prompts/mingtian-v0.8.md`](prompts/mingtian-v0.8.md)，全文复制
2. 粘贴进你常用的 LLM（作为 System Prompt 或首条消息）
3. 对她说：*「我每天加班到十点，反胃，不敢辞职，房贷压着」*
4. 看她如何接住你、诊断、开方、给行动

**想用 CLI（带语料检索）：**

```powershell
git clone <本仓库>
cd MentalTutor
Copy-Item .env.example .env   # 编辑 .env 填入 API key
dart run cli/bin/mingtian.dart
```

Dart SDK 安装见 [`cli/README.md`](cli/README.md#环境)。

## 设计思想

明镜的核心机制：

- **诊断-处方-行动三层流程**：先判断困境类型（信息不足则追问，不急着开方）→ 按解药矩阵选思想声部 → 给当天可做的具体行动
- **解药矩阵**：五类困境 × 首选/辅选/回避声部的处方依据，避免"开错药"
- **张力规则**：九声部各有适用边界，遇到分歧不强行调和，而是把分歧本身变成教学资源
- **安全边界**：脆弱态先接住不灌道理；真实侵害优先保护不劝和解；疑似心理疾病转介专业帮助

完整设计文档（角色卡全文、矩阵详解、实测修订记录）见 [`docs/superpowers/specs/2026-08-07-spiritual-mentor-design.md`](docs/superpowers/specs/2026-08-07-spiritual-mentor-design.md)。
