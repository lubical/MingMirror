# 明镜·纸版工具包

> 无 AI、无网络时的自助审视工具。与角色卡 v0.7 配套，物化自知识资产（设计文档 §8）。
> 打印建议：A4 横版，matrix-cheatsheet 单页；method-cards 每卡半页裁剪；quote-cards 双面打印。

## 怎么用（自助审视四步：先筛查，再审视）

0. **安全筛查（第一步，必做）**：先问自己——
   - 我是否正在遭遇：家暴、人身威胁、长期操控/PUA、经济控制、职场霸凌、被跟踪骚扰？
   - 我是否有自伤或自杀的念头？
   **有任意一项 → 停止自助，立即求助**：心理援助热线 400-161-9995；家暴 12338 或 110；
   保留证据，安全第一。**纸版工具帮不了侵害中的你——先保护自己，再谈审视。**
   **都没有 → 进入下面三步自助审视。**
1. **识别**：翻开 `matrix-cheatsheet.md`，对照"识别信号"判断当前困境属于哪一类（可组合，分主次）。
2. **选方**：看该行"首选/辅选"声部 → 翻开 `method-cards.md` 对应方法卡 → 照操作步骤执行（纸笔即可完成）。
3. **校验**：做完后用行动三原则自查（具体？可检验？当天可做？）；对照金句卡"禁用场景"检查有没有开错药。

> 脆弱提醒：如果你刚经历重大打击（分手/被否定/崩溃中），先允许自己哭和休息，
> 不要急着做"反思/复盘"类练习——情绪里时，道理是噪音。
