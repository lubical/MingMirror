# 方法卡（16 张）

## 卡 1｜控制二分法（斯多葛）
**用途**：反刍焦虑、灾难化想象、为不可控的事烦恼。
**步骤**：
1. 把担心逐条写下来。
2. 每条归入两栏：我控制的 / 我不控制的。
3. 划掉"不控制"栏——它们不归你负责。
4. 给"控制"栏每条定一个今天可做的小行动。
**提醒**：别把"他的看法"放进你控制的栏——那是他的作业。

## 卡 2｜矛盾分析法（毛泽东）
**用途**：多问题缠身、被困难总量吓住。
**步骤**：
1. 把所有烦恼写下来，不筛选。
2. 问：哪一个解决了，其他会跟着松动？——那是主因。
3. 把主因拆成"我能影响的 / 我不能影响的"。
4. 给"我能影响"的部分定一个今天可做的小行动。
**提醒**：主因不是唯一因；先接住情绪再分析。

## 卡 3｜实践-认识循环（毛泽东）
**用途**：不知道方向、想转行但不确定。
**步骤**：
1. 选一件犹豫不决的事，做一次最小的"试吃"。
2. 做完后写下三个词：开心/无聊/害怕/兴奋/疲惫/其他。
3. 从感受中找规律——"我做___时会___，说明我___"。
4. 根据规律调整下一步行动。
**提醒**：光想不做是空转；做了才知道对不对。

## 卡 4｜战略藐视战术重视（毛泽东）
**用途**：被大目标吓住、觉得"不可能做到"。
**步骤**：
1. 写下困难，问自己"这件事历史上有人做到过吗？"——有，就说明不是不可能。
2. 把困难拆成3-5个具体步骤，每一步都认真对待。
3. 选今天能做的最小一步，立刻执行。
4. 每完成一步，记录下来——积累信心。
**提醒**：藐视是心态，重视是行动——两者要同时成立。

## 卡 5｜知足观（老子）
**用途**：攀比焦虑、求而不得、消费后空虚。
**步骤**：
1. 写下你现在拥有的5样东西（健康、关系、技能、物质、经历）。
2. 对想要的东西问自己"没有它我会死吗？"——不会，就是"想要"。
3. 每天睡前写下3件今天值得感恩的小事。
4. 减少刷社交媒体的频率。
**提醒**：知足是心态，不是阻止你改善生活。

## 卡 6｜反者道之动（老子）
**用途**：觉得"到头了"、看不到希望。
**步骤**：
1. 写下现在的困境，不回避。
2. 问自己"这个困境的反面是什么？"——反面就是转机的方向。
3. 别急着突破——先保存体力，等时机。
4. 问自己"哪里可以软一点？"——柔软不是认输，是策略。
**提醒**：转机不会自动来——你需要蓄力和行动。

## 卡 7｜反求诸己（孔子）
**用途**：人际冲突、被误解、关系紧张。
**步骤**：
1. 先别急着说"都是他的错"或"都是我的错"。
2. 问自己"在这个 situation 里，我能控制的是什么？"
3. 针对可控项，定一个今天可做的小行动。
4. 对于不可控的部分，接受它不在你的管辖范围内。
**提醒**：反求诸己是找"我能改变什么"，不是把所有错揽到自己身上。

## 卡 8｜当下观（慧能）
**用途**：反刍思维、灾难化想象、"如果当时……"
**步骤**：
1. 注意到自己在想过去或未来——"我又在想___了"。
2. 问自己"此刻我在做什么？"——把注意力拉回来。
3. 用五感（看/听/摸/闻/尝）感受此刻。
4. 此刻能做的最小的事是什么？去做它。
**提醒**：当下观不是不反思——是不在错误的时间反思。

## 卡 9｜破执观（慧能）
**用途**：放不下、反复纠结、被某件事卡住。
**步骤**：
1. 问自己"我执着的是什么？"——是结果？是评价？是拥有？
2. 这个执着让我付出了什么？时间？健康？关系？
3. 想象把执着的东西放在手掌心，然后慢慢松开手指。
4. 松手后，你腾出了什么空间？可以用它做什么？
**提醒**：破执不是不想——是看见了然后选择放下。

## 卡 10｜结构归因（马克思）
**用途**：觉得"我不够努力"、工作没有价值感。
**步骤**：
1. 把你对自己的批评写下来。
2. 问自己"这个情况里，有哪些是制度/规则/环境造成的？"
3. 把自责的话里属于结构因素的部分划掉。
4. 剩下的部分里，有什么是我可以改变的？
**提醒**：结构归因不是推卸责任——是分清哪些是你的、哪些是制度的。

## 卡 11｜知行合一·事上磨练（王阳明）
**用途**：道理都懂但做不到、想太多做太少。
**步骤**：
1. 你一直想做但没做的事是什么？
2. 今天能做的最小的一步是什么？去做它。
3. 做完后写下感受——这比"想"更能告诉你真相。
4. 根据感受调整下一步。
**提醒**：想了三个月还没动手——先做一次再想。

## 卡 12｜致良知（王阳明）
**用途**：讨好型人格、过度在意别人看法。
**步骤**：
1. 先别管别人怎么说——问自己"我心里觉得什么是对的？"
2. 安静下来，听内心的声音——它通常在安静时最清晰。
3. 做良知告诉你的事，即使别人不赞同。
4. 准备好承担后果。
**提醒**：良知不是"我想怎样就怎样"——是内心深处的是非判断。

## 卡 13｜齐物观（庄子）
**用途**：跟人争论、觉得"我是对的他是错的"。
**步骤**：
1. 先别急着说"我对"或"他错"。
2. 从对方的角度看这件事——他会怎么说？
3. 两个人的"对"有没有共同的地方？
4. 有些事没有绝对的对错——放下争论，做该做的事。
**提醒**：齐物不是否定是非——是看到是非的相对性。

## 卡 14｜消极想象（斯多葛）
**用途**：对未来的恐惧、对失去的焦虑。
**步骤**：
1. 想象你害怕失去的东西真的失去了——工作、关系、健康。
2. 感受那种失去的感觉——它有多可怕？
3. 问自己"即使失去了，我还剩下什么？"
4. 回到现在，珍惜你还拥有的。
**提醒**：想象是为了珍惜，不是为了吓自己——适度就好。

## 卡 15｜意义三源（弗兰克尔）
**用途**：觉得"活着没意思"、工作没有价值感。
**步骤**：
1. 问自己：我现在能做一件创造性的事吗？能认真感受一个人/一件事吗？能在苦难中选一个值得的姿态吗？
2. 三选一，选最可行的。
3. 今天能做的最小的一步是什么？去做它。
4. 做完后写下感受——意义往往在行动后出现。
**提醒**：意义不是找来的——是在行动中感受到的。


## 卡 16｜调查研究（毛泽东）
**用途**：方向迷茫（"不知道想要什么"）、决策前空想纠结。
**步骤**：
1. 把问题拆成可调查的对象（如"要不要换工作"→ 调查"最消耗我的三件事"）。
2. 写具体事实，不写感觉——只记发生了什么。
3. 找参照：问一个"过得还行"的人他每天具体在干什么、哪一刻觉得值。
4. 基于事实做一个最小决定，去做。
**提醒**：调查的产出必须是"一个小决定"——不是无限期"再了解了解"。
